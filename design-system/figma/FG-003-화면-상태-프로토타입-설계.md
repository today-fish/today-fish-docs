# FG-003 화면·상태·프로토타입 설계

> **핵심 결론:** Figma는 Design System / UI Screens / User Flow & Prototype 3페이지로 구성한다. UF-01~06과 주요 예외를 클릭형 Prototype으로 검증하며, 자동 연결이 어려운 인터랙션은 수동 연결 명세로 보완한다.

- 문서 상태: 통합 반영용 초안
- 관련 승인: Q8, Q13~Q15, Q27~Q29, Q32~Q34 및 차트 반응형 후속 개정

## 1. Figma 페이지 체계

| 페이지 | 산출물 |
|---|---|
| `01 · Design System` | Foundations, Primitives, Patterns, Variants |
| `02 · UI Screens` | 홈·품목 상세·탭·채팅 및 화면 상태 |
| `03 · User Flow & Prototype` | UF-01~06, 분기·예외, 실행 가능한 Prototype |

기술적 제약이 입증된 경우에도 페이지 구조를 자동 변경하지 않는다. 대안을 설명하고 사용자 별도 승인 후 변경한다(Q34).

## 2. 화면 및 상태 ID

- `SCR-001`: 홈, 검색, 가격 카드
- `SCR-002`: 품목 상세, 공통 차트와 Price Insight·최근 이슈 탭
- `OVL-CHAT`: 채팅 FAB로 호출하는 오버레이 패널
- 원본 `ST-001~015` 및 해당 예외 상태를 UX-001·002에 따라 표현한다.
- 상세 탭(`TAB-INSIGHT`, `TAB-ISSUES`)은 별도 상세 URL로 재정의하지 않는다.

## 3. UF-01~06 제작 범위

| 흐름 | 사용자 동작 | 주요 검증 |
|---|---|---|
| UF-01 | 홈에서 품목 선택 → 상세 진입 | 상세 초기 상태 |
| UF-02 | 홈 검색 및 결과 선택 | 즉시 필터·결과 없음 |
| UF-03 | 유효 차트 기간 선택 → Insight | 선택 강조·기간 일치·근거 |
| UF-04 | 반월 ↔ 월별 집계 변경 | 기간·Insight 초기화, 활성 탭 유지 |
| UF-05 | 최근 이슈 조회·더보기·원문 | 펼침·스크롤·외부 링크 |
| UF-06 | 채팅 열기·전송·재연결 | 연결 유지·새 메시지 알림·복구 |

- 주요 예외(가격/Insight/이슈 오류, 결측, 채팅 연결 단절 등)는 **별도 Frame**으로 표현한다.
- 단순 시각 변화, 툴팁, 비활성 상태는 **Variant 또는 Overlay**로 표현한다.
- 승인된 모든 UF와 주요 예외 흐름에 실제 클릭 경로를 준비한다.

## 4. 차트·관측 품질 반응형 정책

- 유효 가격 점을 선택하면 해당 점을 강조한다.
- **CSS viewport 767px 이하:** 차트 하단 고정 정보 영역에서 선택 기간·가격·결측 정보를 표시한다.
- **CSS viewport 768px 이상:** 차트 내부 툴팁에서 선택 기간과 평균가격을 표시한다.
- 전환 경계는 767px·768px이며, 모바일 기본 검증 너비는 320px·390px·480px이다. 768px 이상도 넓은 화면 기준으로 검증한다.
- 768px은 접근성 표준이 정한 값이 아니라 오늘의 수산이 선택한 제품 설계 기준이다. 모바일 너비에서 일관된 정보 표시를 유지하고, 좁은 화면의 툴팁이 데이터·축을 가리는 위험을 줄이며, 넓은 화면에서는 데이터 포인트와 선택 정보를 직접 연결한다. 단일 전환점으로 설계·구현·QA를 단순화하고 767px·768px 경계 테스트로 동작을 확인한다.
- 좁은 차트 컨테이너나 화면 가장자리에서 툴팁이 잘리면 위치 조정·경계 처리로 대응하며, 전환 너비는 임의로 변경하지 않는다.
- 결측 안내는 일시적 상호작용 상태로, 기존 유효 선택과 Price Insight를 변경하지 않는다. 유효 선택이 없는 결측 터치는 유효 선택으로 취급하지 않는다.
- 차트 하단에는 관측 일수·시장 수 요약을 표시한다. 인라인 Accordion에서 기간·관측 일수·관측 시장 수·집계 기준을 확인한다.
- 15일 시계열 24개, 월별 12개 점은 유지하고 X축 레이블만 일부 간략 표시한다. 선택 기간명은 온전히 표시한다.

## 5. 채팅 상태 표현

- 패널을 닫아도 기존 연결과 메시지 상태를 보존하며 재열림은 중복 연결을 만들지 않는다.
- 과거 메시지 탐색 중에는 목록 하단 가까이에 신규 메시지 이동 버튼을 두고, 패널 닫힘 상태에서는 FAB Dot으로 새 메시지를 표시한다.
- 메시지가 없을 때의 문구 초안: `아직 메시지가 없어요. 첫 이야기를 시작해 보세요.` 이 문구는 **Draft 카피**이다.
- 채팅 닉네임의 20색 팔레트는 DS-001의 확정 HEX를 따른다. 실제 데이터·서버 세션은 Figma가 시뮬레이션한다.

## 6. 프로토타입 연결·검증

1. 자동 생성 가능한 연결 기능을 **읽기 전용으로 먼저 확인**한다.
2. 실제 생성 테스트는 사용자 별도 승인 후 한다.
3. 자동화할 수 없는 동작은 시작 프레임, 이벤트, 조건, 목적 프레임, 기대 결과가 포함된 수동 연결 명세로 보완한다.
4. Figma Present에서 모든 UF와 주요 예외 경로를 실행한 결과를 `FV-001`의 Prototype 열에 기록한다.
5. 구현 UI·E2E는 별도 검증 단계로 분리한다. 정적 프레임이 있거나 수동 명세가 있다는 이유만으로 Prototype PASS를 부여하지 않는다.

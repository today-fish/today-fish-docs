오늘의 수산

오늘의 가격,
바다의 이야기

가격은 명확하게, 바다의 이야기는 친근하게.

이 문서의 브랜드 슬로건과 3색 방향은 사용자 선택을 반영했습니다. 색상 사용처, 타입, 차트 규격과 컴포넌트는 검토용 제안입니다. 샘플 가격은 모두 가상 데이터입니다.
01 / BRAND

브랜드 원칙

정보 경험은 믿음직하게, 브랜드의 인상은 가볍고 생생하게. 정보 서비스의 진지함과 친근함을 함께 유지합니다.

01 / CLARITY

명확함

가격, 단위, 기준 기간을 가장 먼저 읽을 수 있도록. 장식보다 정보의 위계를 우선합니다.

02 / TRUST

신뢰

실제 가격·공식 출처·AI 해석을 구분하고, 모르는 정보는 추측해 채우지 않습니다.

03 / LIVELINESS

생동감

주요 액션에는 선명한 오션 블루를, 산뜻한 발견의 순간에는 민트를 제한적으로 사용합니다.

04 / FRIENDLY

친근함

어려운 숫자를 쉬운 문장과 예측 가능한 인터랙션으로 설명합니다.

05 / DISCOVERY

발견

가격 변화에서 Price Insight와 관련 소식으로 이어지는 맥락을 제공합니다.

계절감은 콘텐츠의 표현 언어로 활용하되, MVP에 없는 제철 추천 기능을 새로 도입하지 않습니다.

10 / GOVERNANCE

디자인 시스템 사용 규칙

디자인은 이 HTML의 승인된 토큰을 기준으로, 기능·데이터 정책은 기존 PRD/PD/PF/PP/UX를 기준으로 관리합니다.

정식 승인 이후 제한

  1. 등록된 Primitive / Semantic / Component 토큰만 사용합니다.
  2. 임의 HEX, 임의 font-size, spacing, radius, box-shadow를 신규 추가하지 않습니다.
  3. 새 컴포넌트 변형 또는 Lucide 외 기능 아이콘은 먼저 변경 제안을 제출합니다.
  4. 누락 토큰은 기존 토큰으로 처리 가능한지 확인하고 승인 후 HTML과 구현을 동기화합니다.
  5. 접근성, 반응형, 상태 표현은 컴포넌트별 검증합니다.

현재 Draft의 적용 범위

  1. 슬로건 및 기본 3색 방향은 사용자 선택 완료입니다.
  2. 파생 팔레트, 차트 색상·기하학, 아이콘 크기, 레이아웃 수치는 아직 초안입니다.
  3. 검증·승인 전에는 본 HTML의 모든 세부 토큰을 강제로 적용하지 않습니다.
  4. 제품 MVP 범위를 바꾸는 기능 제안은 디자인 문서만으로 승인하지 않습니다.
  5. 최종 승인 후 버전 및 변경 이력을 기록합니다.
디자인 문서만으로 Codex의 모든 임의 스타일 사용을 자동 방지할 수는 없습니다. 실제 프로젝트에서는 저장소 규칙, 공유 토큰 파일, 린트/CI 검증을 함께 적용해야 합니다. 이 HTML은 시각적 기준이며 제품 정책을 수정하지 않습니다.

채팅 UI 데모

아래 버튼으로 새 메시지, 연결 상태, 전송 오류 등 다양한 화면 상태를 체험할 수 있습니다. FAB는 브라우저 우측 하단에 고정됩니다. 새 메시지는 아래에서 위로 나타나며 메시지 목록만 스크롤됩니다. 입력창은 패널 하단에 유지됩니다.

이 시연에서는 패널을 닫아도 데모 메시지와 상태를 유지하며, 다시 열면 목록 맨 아래로 이동합니다. 실제 서버 연결이나 세션을 생성·유지하는 구현은 아니며, 서비스 연결 정책은 UX-002와 PF-005를 따릅니다.

UI 시험을 위한 샘플 닉네임·색상입니다. 서버의 500×20 조합 할당을 구현하지 않습니다. 닉네임 20색 HEX 팔레트는 Q26 승인 완료이며, 실제 표시 배경의 텍스트 대비 4.5:1 이상과 색각 구분성은 검증 별도입니다.

# 오늘의 수산 디자인 시스템

> **핵심 결론:** `v0.5.1 Draft`는 현재 저장소에 편입할 **최신 디자인 미리보기**입니다. 기능·데이터 정책은 `MVP/product/`가 우선이며, 디자인 미리보기를 실제 서비스 구현으로 간주하지 않습니다.

| 항목                  | 현재 상태                                        |
| --------------------- | ------------------------------------------------ |
| 최신 산출물           | `v0.5.1 Draft` (정식 릴리스 아님)                |
| 디자인 방향           | Ocean Minimal + Fresh & Friendly                 |
| 슬로건                | **오늘의 가격, 바다의 이야기**                   |
| 대표 컬러             | Ocean `#007FAD` · Mint `#17D4B4` · Red `#E53935` |
| 미리보기              | [preview/index.html](./preview/index.html)       |
| 토큰                  | [tokens/tokens.json](./tokens/tokens.json)       |
| 디자인 상태·승인 사항 | [DS-001](./DS-001-디자인-시스템-현황.md)         |

## 사용 방법

1. `preview/index.html`을 브라우저에서 열어 컴포넌트와 인터랙션 데모를 확인합니다.
2. 구현에 사용되는 수치형 토큰 후보는 `tokens/tokens.json`을 확인합니다. **제안 토큰은 승인된 규칙으로 간주하지 않습니다.**
3. 동작과 정보 신뢰 정책은 `MVP/product/features/`, `MVP/product/policies/`, `MVP/product/ux/`의 문서를 우선 참조합니다.
4. 디자인 변경 전에 사용자 승인을 받고, 변경된 HTML·JSON·DS-001을 함께 점검합니다.

## 버전 및 이력 관리

- 이 폴더에는 **최신 파일만** 유지합니다. 과거 버전의 변경 내용과 승인 근거는 **GitHub PR 및 Git 이력**으로 확인합니다.
- 버전 표시와 제품 승인 상태는 별개입니다. `Draft`인 시각·모션·반응형 수치를 임의로 확정하지 않습니다.
- 변경 요청이 디자인 이외의 제품 정책과 충돌할 경우 사용자 검토 후 해당 원본 문서에서 결정합니다.

## 한계

HTML은 가상 데이터를 이용한 디자인 데모이며 실제 KAMIS 조회, AI 분석, 채팅 서버, 외부 근거 원문 기능을 제공하지 않습니다. 원문 URL이 없는 가상 출처는 클릭 가능한 링크로 위장하지 않습니다. 자동 생성 파이프라인과 실기기 접근성 검증도 아직 완료되지 않았습니다.

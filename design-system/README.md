# 오늘의 수산 디자인 시스템

- **버전:** V1
- **상태:** 승인

이 영역은 디자인 시스템의 현황, Figma 제작 기준, 요구사항 추적과 UI 검증 기준을 관리한다. 제품 동작은 PRD·PF·UX를, 디자인 상세와 산출물 상태는 각 원본 문서를 따른다.

## 현황과 산출물

문서 버전은 V1이며 현재 미리보기 산출물은 `v0.5.1 Draft`다. 문서 승인과 시안·토큰의 개별 승인은 구분한다. 미리보기는 가상 데이터 기반 디자인 데모이며 실제 API·AI·채팅 서버의 구현 완료를 나타내지 않는다.

# DS-001 디자인 시스템 현황

> **핵심 결론:** 최신 시각 미리보기는 `v0.5.1 Draft`이며, 브랜드·공통 컴포넌트·가격 차트·익명 채팅·Price Insight의 디자인 시안을 포함합니다. 사용자 승인된 UX와 아직 미승인인 세부 수치를 구분해 관리합니다.

- 문서 상태: `DRAFT`
- 산출물: [HTML 미리보기](./preview/index.html) · [토큰 JSON](./tokens/tokens.json)

## 1. 디자인 기본 방향

- 브랜드: **오늘의 가격, 바다의 이야기**
- 컨셉: **Ocean Minimal + Fresh & Friendly**
- 핵심 컬러: Vivid Ocean Blue `#007FAD`, Fresh Mint `#17D4B4`, Clear Red `#E53935`
- 모바일 웹 우선; 가격·출처 정보의 신뢰성과 친근한 표현을 함께 고려
- 기본 서체는 Pretendard를 사용합니다. Figma에서 사용할 수 없으면 Noto Sans KR을 대체 서체로 우선 검토하고, 웹은 Apple SD Gothic Neo·Malgun Gothic 등 시스템 서체 Fallback을 우선 사용합니다.

## 2. 구현된 디자인 데모

| 영역 | 포함 사항 |
|---|---|
| Foundations | 컬러, 서체, 간격, 아이콘, 상태, 반응형과 모션 예시 |
| 공통 UI | 버튼·입력·모달·팝업·햄버거 메뉴 및 상태 |
| 가격 차트 | 반월/월별 탐색, 선택 툴팁, 결측 등의 인터랙션 예시 |
| 채팅 | 우측 하단 FAB, 슬라이드 패널, 메시지 표시·입력·스크롤 및 상태 데모 |
| Price Insight | 단일 리포트, **분석 결과 / Why?**, 출처, 상태 전환 데모 |

## 3. Price Insight 승인 UX

- **단일 리포트**. 검증된 결과는 일반 배경의 **분석 결과**, 가능한 해석은 연한 블루 배경의 **Why?** 영역에 배치합니다.
- 내부 정보 신뢰 수준은 **확인된 사실 / 가능한 해석 / 파악 중**을 유지합니다. 사용자에게 표시되는 제목 변경이 데이터의 의미를 바꾸지 않습니다.
- 가능 요인은 확인된 근거가 있을 때만 최대 3개, 세로 목록으로 표시합니다. AI 영역 하단에는 인과관계 단정을 피하는 상시 안내 문구를 둡니다.
- 상단에 선택 기간 Chip·평균가격·`분석 기준: YYYY.MM.DD`를 표시합니다. 긴 분석 설명은 기본 4줄, `더보기`로 펼칩니다.
- 설명 아래 근거의 출처명·발행일을 표시하고, 실제 원문 URL이 있으면 새 탭으로 엽니다. 하단 근거 목록은 구분선 형태입니다. 원문 링크 아이콘은 **Lucide `square-arrow-out-up-right` (Square Arrow Out)**입니다.
- 기간 미선택: 아이콘 + 안내 / AI 미생성·근거 부족: 가격·검증된 사실을 유지하고 `Why?` 안에 `파악 중` 카드 / 로딩: 기간·가격 유지, 나머지 스켈레톤 / API 오류: Insight 전체 오류 및 `다시 시도` / 근거 0개: 영역 유지 및 안내.
- 가격 선택과 집계 단위 변경, 차트·Insight 상태 전이는 기존 `PF-003`, `PP-002`, `UX-002` 요구사항을 따릅니다.

## 4. 익명 채팅 승인 UX

- **승인 근거:** 2026-10-16 사용자 승인으로 기존 상세 화면 채팅 탭을 대체하는 우측 하단 FAB 및 오버레이 패널 진입 구조를 확정했습니다.
- 상세 화면 우측 하단 고정 FAB, 새 메시지 존재 여부만 Dot으로 표시
- 닉네임 팔레트 HEX (Phase 1 Q26 승인 순서): `#D21309`, `#B64408`, `#8F5F06`, `#716B05`, `#577205`, `#387705`, `#177A05`, `#057A17`, `#057939`, `#05775B`, `#05757B`, `#076FA7`, `#0A5CF3`, `#3B45F7`, `#6A3BF7`, `#9620F6`, `#B109CF`, `#C008A5`, `#CB0874`, `#D1093B`
- 닉네임 색상은 실제 사용 배경에서 일반 텍스트 대비 4.5:1 이상이어야 합니다. 테마별 색상 매핑 및 색상 외 닉네임 텍스트 병기를 유지합니다.
- 패널을 닫아도 채팅 연결과 메시지 상태를 유지하며, 재열림은 기존 연결을 사용하고 중복 세션·연결을 만들지 않습니다. 재열림 시 최신 메시지로 이동하며 닫기 전 스크롤 위치는 복원하지 않습니다.
- FAB `56px`, 화면 여백 `20px`, 채팅 패널 높이 `55dvh`, 열림·메시지 모션 `180ms`·`200ms`는 Q46의 **조건부 채택 시안 기준(Draft)**이다. 최종 승인값이나 확정 토큰으로 취급하지 않습니다.
- 패널: 모바일 전체 너비·데스크톱 우측 고정 너비, 단일 높이
- 아래→위 열림, 배경 딤, X·바깥 터치·아래 스와이프 닫기
- 품목·연결 상태·본인 닉네임과 색상 헤더, 모든 메시지 왼쪽 둥근 말풍선, 내 메시지는 연한 블루
- Enter/전송 버튼으로 발송, Shift+Enter 줄바꿈, 입력창 자동 확장, 입력창 하단 고정·메시지 목록 내부 스크롤
- 새로운 메시지 아래→위 등장 애니메이션; 하단이면 자동 스크롤, 과거 메시지를 읽는 중에는 새 메시지 이동 버튼
- 서버 세션·메시지 한도 등 기능 정책은 `PF-005`를 따르며 데모만으로 서버 기능 구현을 주장하지 않습니다.

## 5. 검증 및 미승인 항목

- 채팅 닉네임 팔레트의 실제 배경 대비 충족 여부와 색각 구분성은 **미검증**이며, 실제 배경별 검증이 필요합니다.
- FAB·패널·모션의 Q46 조건부 채택 시안 값 및 Price Insight 세부 시각 토큰 등 `proposed` 상태의 값은 최종 승인 전까지 Draft입니다.
- 실제 모바일 브라우저·키보드·터치·접근성 검증
- 토큰 JSON과 HTML의 자동 동기화·프론트엔드 소비 규칙 정립
- 페이지 이탈·브라우저 종료·서버 측 연결 종료의 세션 정리 방식은 기존 기술 설계 보류 사항이며 이 문서에서 새로 확정하지 않습니다.

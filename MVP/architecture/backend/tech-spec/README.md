## 처리 흐름

001 공공 API 수집·검증과 003 PDF·뉴스 추출·검증은 독립적인 병렬 입력 경로다. 검증된 가격 입력은 002에서 집계되고, 003의 검증된 Fact·Evidence와 002의 가격 결과는 004에서 결합되어 Insight 생성·검증·원자적 게시에 사용된다.

```text
001 공공 API 수집·검증 ─────────┐
                                ├──> 002 가격 적격성·대표가격·월/반월 집계 ──┐
003 PDF·뉴스 추출·검증 ─────────┘                                             ├──> 004 Insight 생성·검증·전체 원자적 게시
       └── 검증된 Fact·Evidence ──────────────────────────────────────────────┘
```

003의 상세 책임은 수집·추출·검증까지이며, Insight 입력 선정·생성·검증·게시 정책은 004가 담당한다. 테이블과 관계의 세부 기준은 ERD를 따른다.

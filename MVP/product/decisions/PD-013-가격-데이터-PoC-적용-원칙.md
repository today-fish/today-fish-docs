# PD-013 가격 데이터 PoC 적용 원칙

- **버전:** V1

## Status

승인

## 배경

`POC-003`은 당시 KAMIS 가격 데이터와 공공데이터포털 정산정보를 이용해 가격 차트, 결측 처리, 품목 코드 매핑의 기술적 구현 가능성을 확인했다. 이 실험 원천과 결과는 현행 수집 정책의 근거와 구분한다.

PoC 결과에는 기술 검증뿐 아니라 최초 제공 품목과 데이터 분류 방식에 관한 제품 판단도 포함되어 있었다. 기존 `PD-009`, `PD-010`, `PD-012`와 역할을 명확히 구분하기 위해 PoC 결과의 적용 범위를 결정한다.

## Decision

### 현행 가격 데이터 원천과 가격 유형

- MVP 공공 API 수집 원천은 aT 정산정보와 KMI 유통정보다. KAMIS는 현행 MVP 수집 대상에서 제외한다.
- 발간행물과 기사는 공공 API와 별도 수집 경로로 관리하며, 검증 전 수치를 가격 집계 입력으로 자동 사용하지 않는다.
- 산지가격과 도매가격을 독립적으로 산출하고 차트 한 개에 두 선으로 표시한다. 가격 유형 또는 기준 원천이 다른 관측값을 하나의 표본 집합으로 합치지 않는다.
- 수집·정규화·검증은 [BE-TECH-SPEC-001](../../architecture/backend/tech-spec/BE-TECH-SPEC-001-데이터-수집-정규화-검증.md), 가격 모델과 집계는 [BE-TECH-SPEC-002](../../architecture/backend/tech-spec/BE-TECH-SPEC-002-가격-데이터-모델링-및-산지-도매가격-산출.md)를 따른다.

### PoC와 제품 결정의 역할

PoC는 구현 가능성과 데이터 특성을 확인하는 근거 문서다. PoC 결과만으로 기존 Accepted 제품 결정을 자동으로 변경하지 않는다.

가격 정책은 `PD-009`, 데이터 신뢰 원칙은 `PD-010`, MVP 품목 선정 기준은 `PD-012`를 Source of Truth로 사용한다.

### 초기 제공 품목

갈치·고등어·전복은 가격 데이터 연속성과 차트 구현을 확인한 **개발 검증 품목**으로 채택한다.

후속 제품 검토에서 다음 기준을 확인했다.

* 생산·출하 데이터 확보 가능성
* 환경 또는 시장 이슈 존재 여부
* 뉴스 및 공식자료 확보 가능성
* Price Insight 가치를 보여주기에 적합한지

검토 결과 갈치·고등어·전복을 MVP **최초 제공 품목**으로 확정한다.

### 대표가격 집계

가격 유형별 기준 원천과 상품 조건에 따라 관측값을 독립적으로 집계한다. 산지가격과 도매가격, 서로 다른 기관·데이터셋은 한 표본 집합으로 합치지 않는다.

가격 관측은 다음 조건을 확인한다.

* 내부 어종과 외부 코드의 매핑 수준 및 가격 유형이 확인되는지
* 기준 원천, 단위, 통계 의미, 관측 기준일 및 상품 조건이 비교 가능한지
* 출처와 원문 위치를 추적할 수 있고 완전 중복·단위 오류·파싱 오류가 없는지

동일 날짜·어종·가격 유형·기준 원천·비교 가능한 상품 조건·표준 단위로 묶은 일별 그룹의 유효 독립 원본 관측값에 표본 수 규칙을 적용한다. 0건이면 일별 가격을 산출하지 않고, 1~4건이면 중앙값, 5건 이상이면 최고값과 최저값을 각 1건 제외한 산술평균을 적용한다. 이 규칙에 따른 집계 제외는 원본 관측 삭제를 뜻하지 않으며 정상 극단값도 원본에 보존한다.

반월·월 가격은 유효 일별 가격을 단순 산술평균한다. 반월은 1~15일 및 16일~월말, 월별은 1일~월말이다. 관측이 없는 날짜는 평균에서 제외한다. 결측값은 0·직전값·보간 또는 다른 가격 유형·원천으로 대체하지 않는다.

### 원천 매핑 및 검증 상태

원본 응답과 매핑·정규화 결과를 구분해 보존한다. 외부 품목 코드의 `GROUP` 매핑은 상품 조건의 동등성이나 가격 비교 가능성을 보장하지 않는다.

`VALID`, `REVIEW_REQUIRED`, `INVALID` 상태를 구분한다. `VALID`는 기본 형식·값 검증 통과를 뜻하며 가격 집계 적합성을 자동 확정하지 않는다. 가격 유형·기준 원천·단위·상품 조건·독립 관측 여부가 불명확한 값은 검토 또는 제외하고, 검증 사유와 원본 출처를 보존한다.

### 결측값

가격이 없는 기간은 0원이나 보간값으로 대체하지 않는다. 차트의 선을 끊고 데이터 부재, 수집 오류, 비교 조건 불일치 등 확인 가능한 상태를 구분해 표시한다.

## Consequences

* `POC-003`은 당시 KAMIS·정산정보 실험 결과와 초기 품목 선정 근거를 기록하며 현행 가격 원천을 정의하지 않는다.
* 갈치·고등어·전복을 초기 제공 품목으로 사용한다.
* aT 정산정보와 KMI 유통정보의 관측값은 가격 유형과 기준 원천별로 검증·집계한다.
* 원본 극단값과 검증된 집계 제외 기록을 보존한다.

## Follow-up

* aT·KMI 원천별 상품 조건 및 코드 매핑의 비교 가능성 검증
* 발간행물·기사에서 추출한 가격의 별도 검증 기준과 Price Insight 노출 수준 결정

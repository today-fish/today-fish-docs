# PP-002 AI 분석 운영 정책

> **핵심 결론:** Price Insight는 하루 1회 AI 분석을 수행하고 결과를 저장한다. 사용자 조회 시 저장된 결과를 제공하며, 확인된 사실과 가능한 해석을 구분한다. 근거가 부족하거나 분석에 실패하면 AI 해석만 `파악 중`으로 처리한다.

- **상태:** DRAFT
- **상위 문서:** [PRD-001](../PRD-001-MVP-제품-요구사항.md)
- **관련 기능:** [PF-003 Price Insight](../features/PF-003-Price-Insight.md), [PF-004 최근 이슈](../features/PF-004-최근-이슈.md)
- **기존 의사결정:** PD-008, PD-009, PD-010, PD-011, PD-013

---

## 1. AI 역할

| 구분 | 역할 |
|---|---|
| 데이터 수집·정리 | 뉴스·공공자료 수집, 중복 제거, 출처 및 기간 관련성 관리 |
| AI 분석·해석 | 가격 데이터와 확인된 사실을 종합하여 가격 변동 가능 요인 도출 |
| 결과 검증 | 근거 확인, 사실·해석 구분, 인과관계 단정 방지 |

- 가격 계산은 기존 가격 데이터 정책을 따르며 AI가 임의 수정하지 않는다.
- 수집된 외부 자료를 신뢰된 시스템 명령으로 취급하지 않는다.
- AI가 생성한 내용을 검증 없이 확인된 사실로 게시하지 않는다.

## 2. 분석 실행 정책

| 항목 | 정책 |
|---|---|
| 실행 주기 | 하루 1회 자동 분석 |
| 실행 방식 | 배치 처리 후 결과 저장 |
| 사용자 조회 | 저장된 결과 반환 |
| 분석 단위 | 품목 + 집계 단위 + 시작일 + 종료일 |
| 집계 단위 | 15일 / 월별 |
| 가능 요인 | 최대 3개, 근거 부족 시 0개 허용 |
| 재분석 | 신규 근거 또는 가격 데이터 변경 시 |

- 사용자 조회마다 AI 모델을 호출하지 않는다.
- 월별 분석은 해당 월 전체를 별도로 분석한다.
- 과거 기간 분석에는 최근 30일 이전의 관련 자료도 활용한다.
- 변경되지 않은 유효 분석은 재사용한다.

## 3. 분석 신뢰 정책

| 구분 | 표시 기준 |
|---|---|
| 확인된 사실 | 가격 데이터 또는 검증 가능한 출처로 확인된 정보 |
| 가능한 해석 | 확인된 사실을 근거로 AI가 제시하는 설명 가능성 |
| 파악 중 | 분석 미생성·실패 또는 근거 부족 |

**금지 사항**

- 검증되지 않은 가격 변동 인과관계 단정
- 존재하지 않는 출처·통계·사건 생성
- 품목이나 기간이 관련되지 않은 자료 사용
- 거래량과 가격의 동시 변화를 확정 원인으로 설명
- 세부 상품 매핑이 검증되지 않은 데이터를 동일 상품의 확정 근거로 사용

외부 근거에는 출처명, 문서 제목, 발행일, 원문 URL을 연결한다.

## 4. 분석 결과 관리

분석 결과는 다음 정보를 보존한다.

- 분석 대상: 품목, 집계 단위, 시작일, 종료일
- 분석 내용: 확인된 사실, 가능한 해석, 관련 근거
- 생성 이력: 생성 시각, 갱신 시각, 분석 버전
- 데이터 연결: 사용된 가격 데이터 버전
- 실행 상태: 성공, 실패, 재분석 필요 여부

가격 또는 관련 근거가 변경되면 영향을 받는 분석을 식별하고 갱신한다.

무효화된 분석 결과를 정상 분석으로 제공하지 않는다.

## 5. 장애 및 예외 처리

| 상황 | 처리 정책 |
|---|---|
| AI 분석 미생성 | AI 해석만 `파악 중` |
| AI 분석 실패 | 가격·확인된 사실 유지, 실패 기록 |
| 근거 부족 | 요인 임의 생성 금지 |
| 출처 검증 실패 | 해당 근거를 확인된 사실로 사용하지 않음 |
| 가격 데이터 변경 | 관련 분석 재검토 및 재분석 |
| 외부 자료 수집 실패 | 실패 기록, 유효한 기존 자료 보존 |
| 중복 분석 실행 | 동일 결과의 비정상 덮어쓰기 방지 |

가격 데이터와 AI 분석의 상태는 독립적으로 관리한다.

## 6. 운영 및 비용

- 하루 1회 배치 분석을 기본으로 한다.
- 사용자 요청별 실시간 AI 분석을 수행하지 않는다.
- 유효한 분석 결과를 재사용한다.
- 변경이 발생한 기간을 중심으로 재분석한다.
- AI 호출량, 비용, 분석 성공·실패 이력을 기록한다.
- API 인증정보는 서버에서만 관리한다.

## 7. 출시 인수 조건

- [ ] 하루 1회 자동 분석 및 결과 저장
- [ ] 사용자 조회 시 저장된 분석 반환
- [ ] 반월·월별 분석 결과 구분
- [ ] 확인된 사실·가능한 해석·파악 중 구분
- [ ] 가능 요인 최대 3개 제한
- [ ] 외부 근거의 출처 추적 가능
- [ ] 검증되지 않은 인과관계 단정 방지
- [ ] AI 분석 실패 시 가격·확인된 사실 유지
- [ ] 가격 및 근거 변경에 따른 재분석 가능
- [ ] 분석 실행·실패 이력 확인 가능

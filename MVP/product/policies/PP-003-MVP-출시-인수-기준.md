# PP-003 MVP 출시 인수 기준

> **핵심 결론:** 오늘의 수산 MVP는 핵심 기능, 데이터 신뢰성, 운영 안정성의 세 가지 조건을 모두 충족해야 출시할 수 있다. 필수 요구사항에 미충족 항목이 있거나 가격·AI 분석의 신뢰성을 보장할 수 없는 경우 출시를 보류한다.

- **문서 상태:** DRAFT
- **상위 문서:** [PRD-001 MVP 제품 요구사항](../PRD-001-MVP-제품-요구사항.md)
- **관련 정책:** [PP-002 AI 분석 운영 정책](./PP-002-AI-분석-운영-정책.md)
- **적용 범위:** 모바일 웹 MVP
- **출시 대상:** 갈치·고등어·전복

---

## 1. 출시 판정 원칙

MVP 출시 여부는 다음 세 영역을 기준으로 판단한다.

| 영역 | 검증 목표 |
|---|---|
| 핵심 기능 | 사용자가 가격과 분석 정보를 정상적으로 조회할 수 있는가? |
| 데이터 신뢰성 | 가격 계산과 AI 분석이 검증된 정책을 준수하는가? |
| 운영 안정성 | 데이터 수집·분석 장애를 감지하고 정상 기능을 유지할 수 있는가? |

### 판정 상태

- `PASS`: 필수 인수 조건 충족
- `FAIL`: 필수 인수 조건 미충족
- `PENDING`: 검증 미완료 또는 기준 미확정

**출시 조건:** 모든 필수 항목이 `PASS`여야 한다. `FAIL` 또는 `PENDING`인 필수 항목이 존재하면 출시를 보류한다.

## 2. 핵심 기능 인수 기준

### 2.1 홈 화면 — PF-001

- [ ] 갈치·고등어·전복 3종 표시
- [ ] 최근 확정 평균가격 및 변동률 표시
- [ ] 가격 단위와 기준 기간 확인 가능
- [ ] 가격 결측 시 임의 가격 표시 금지
- [ ] 품목 선택 시 해당 상세 화면 이동
- [ ] 갈치·고등어·전복 이름 검색 및 미지원 품목 결과 없음 처리
- [ ] 로그인 없이 이용 가능

### 2.2 가격 차트 — PF-002

- [ ] 최근 1년 가격 차트 제공
- [ ] 기본 집계 단위 15일
- [ ] 15일·월별 전환 가능
- [ ] 차트 점 터치로 기간 선택 가능
- [ ] 선택 기간 평균가격 표시
- [ ] 집계 단위 변경 시 기존 선택 초기화
- [ ] 결측 구간의 차트 선 연결 금지
- [ ] 관측일 수와 시장 수 확인 가능

### 2.3 Price Insight — PF-003

- [ ] 선택한 가격 기간의 분석 조회
- [ ] 최초 진입 시 기간 선택 안내
- [ ] 확인된 사실·가능한 해석·파악 중 구분
- [ ] 가격 변동 가능 요인 최대 3개
- [ ] 출처명·제목·발행일·원문 링크 제공
- [ ] 월별 선택 시 해당 월 전체 분석 제공
- [ ] AI 해석이 없어도 가격과 확인된 사실 유지

### 2.4 최근 이슈 — PF-004

- [ ] 뉴스 및 공공기관 자료 조회
- [ ] 최근 30일 자료 표시
- [ ] 발행일 최신순 정렬
- [ ] 최초 최대 5개 표시
- [ ] 더보기 기능 정상 동작
- [ ] 동일 URL 중복 제거
- [ ] 서로 다른 URL의 자료는 개별 유지
- [ ] 원문 링크 새 탭 열기
- [ ] 과거 Insight 근거 조회와 30일 필터 분리

### 2.5 실시간 채팅 — PF-005

- [ ] 회원가입·로그인 없이 채팅방 진입
- [ ] 갈치·고등어·전복 채팅방 분리
- [ ] 텍스트 메시지 전송 및 실시간 수신
- [ ] 임시 표시 이름과 작성 시각 표시
- [ ] 연결 상태 표시 및 재연결
- [ ] 메시지 길이와 전송 빈도 제한
- [ ] 채팅 장애 시 가격 차트와 Price Insight 정상 유지
- [ ] 출시 전 최소 Moderation 범위 확정

## 3. 데이터 신뢰성 인수 기준

### 3.1 대표 가격

- [ ] KAMIS 중도매 가격 사용
- [ ] 국산 생물 운영상 분류 규칙 적용
- [ ] 원본 상품명 및 분류 결과 보존
- [ ] 동일 날짜의 적격 시장가격 단순평균
- [ ] 유효 일별 평균가격의 기간별 단순평균
- [ ] 월별 평균을 두 반월 평균의 단순평균으로 대체하지 않음
- [ ] 가격 단위 정규화 및 계산 결과 검증
- [ ] 정산정보 가격으로 대표 가격 대체 금지

### 3.2 결측 및 오류

- [ ] 결측 가격을 0원으로 표시하지 않음
- [ ] 이전 가격 복사 및 임의 보간 금지
- [ ] 냉동·수입산 가격으로 생물 가격 대체 금지
- [ ] 수집 실패와 실제 관측자료 없음 구분
- [ ] 관측일 수와 시장 수 확인 가능
- [ ] 데이터 품질 미달 처리 기준 확정 및 적용

### 3.3 AI 분석 신뢰성

- [ ] 가격 데이터와 AI 해석 분리
- [ ] 확인된 사실과 가능한 해석 구분
- [ ] 검증되지 않은 인과관계 단정 금지
- [ ] 외부 근거의 원문 추적 가능
- [ ] 품목·기간에 맞는 근거 사용
- [ ] 근거 부족 시 `파악 중` 처리
- [ ] 가격 또는 근거 변경 시 관련 분석 재검토 가능

## 6. KPI 측정 준비

MVP의 핵심 KPI는 **Price Insight 이용률**이다.

**정의**

수산물 상세 화면 방문자 중 Price Insight를 1회 이상 조회한 익명 이용자의 비율.

**계산식**

Price Insight 이용률(%) =
(Insight 조회 익명 이용자 수 / 상세 화면 방문 익명 이용자 수) × 100

### 인수 조건

- [ ] 상세 화면 방문 이벤트 수집
- [ ] Price Insight 조회 이벤트 수집
- [ ] 중복 조회를 구분할 수 있는 측정 정책 적용
- [ ] 익명 이용자 식별 방식 확정
- [ ] 출시 후 30일 성과 측정 가능
- [ ] 개인정보 수집·보존 정책 검토

KPI 목표값은 출시 전 별도 확정한다.

## 7. 출시 차단 기준

다음 중 하나라도 발생하면 출시를 보류한다.

1. 갈치·고등어·전복 중 필수 가격 조회 기능이 정상 작동하지 않는 경우
2. 가격 집계 산식이 승인된 정책과 다른 경우
3. 결측값을 0원이나 임의 가격으로 표시하는 경우
4. 검증되지 않은 인과관계를 확정적인 원인으로 제공하는 경우
5. AI 분석 장애로 정상 가격 조회가 중단되는 경우
6. 출처가 없는 AI 생성 주장을 확인된 사실로 게시하는 경우
7. 필수 기능의 인수 테스트가 실패한 경우
8. 필수 데이터 품질·보안·운영 기준이 미확정이거나 검증되지 않은 경우
9. 품목별 채팅방이 격리되지 않거나 비로그인 메시지 송수신·재연결이 정상 작동하지 않는 경우
10. 채팅의 최소 Moderation 및 전송 제한 기준이 확정되지 않은 경우

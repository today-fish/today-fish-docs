# PF-001 홈 화면

> **핵심 결론:** 오늘의 수산 MVP 홈 화면은 갈치·고등어·전복 3종을 갈치→고등어→전복 순서로 제공하고 이름 입력 즉시 지원 품목을 필터링한다. 대표 가격은 가장 최근 완료 반월만 사용하며 해당 반월이 결측이면 이전 가격으로 대체하지 않는다. 카드별 기준 기간과 홈 최근 갱신 시각을 표시하고, 품목별 오류는 해당 카드를 유지한 채 재시도할 수 있게 한다.
>
> - 문서 상태: DRAFT
> - 상위 문서: [PRD-001 MVP 제품 요구사항](../PRD-001-MVP-제품-요구사항.md)
> - 상위 기능: `CAP-HOME`
> - 관련 문서: [PF-002 수산물 가격 차트](./PF-002-수산물-가격-차트.md), [PF-005 실시간 채팅](./PF-005-실시간-채팅.md)
> - 관련 정책: PP-001 가격 데이터 처리 정책(작성 예정)
> - 적용 플랫폼: 모바일 웹
> - 우선순위: MVP 필수

## 1. 기능 목적

홈 화면은 사용자가 서비스에 진입했을 때 현재 제공하는 수산물과 가격 현황을 빠르게 파악하고, 관심 있는 품목의 상세 분석으로 이동하도록 돕는다.

### 사용자 목표

1. 현재 제공하는 수산물 3종을 확인한다.
2. 품목별 최근 확정 평균가격을 확인한다.
3. 직전 비교 기간 대비 가격 변화 방향과 변동률을 확인한다.
4. 관심 있는 수산물의 상세 화면으로 이동한다.
5. 초기 지원 품목을 이름으로 검색한다.

### MVP 설계 원칙

- 수산물 목록을 중심으로 단순하게 구성한다.
- 회원가입과 로그인 없이 이용할 수 있다.
- 가격 정보를 우선적으로 노출한다.
- 가격은 실제 관측자료를 기반으로 계산한다.
- 데이터가 없는 경우 정확한 상태를 표시한다.
- 복잡한 정보와 분석 내용은 상세 화면에서 제공한다.

## 2. 화면 구성

### 2.1 홈 화면 기본 구조

홈 화면은 다음 영역으로 구성한다.

| 영역 | 표시 정보 | 필수 여부 |
|---|---|---|
| 서비스 헤더 | 오늘의 수산 | 필수 |
| 서비스 안내 | 서비스의 목적을 설명하는 짧은 문구 | 필수 |
| 품목 검색 | 갈치·고등어·전복 이름 검색 | 필수 |
| 수산물 목록 | 갈치·고등어·전복 | 필수 |
| 품목별 가격 | 최근 확정 평균가격 | 필수 |
| 품목별 변동률 | 비교 기준 대비 상승·하락·변동 없음 | 필수 |
| 데이터 기준 안내 | 가격 정의 및 기준 기간 | 필수 |
| 최근 갱신 안내 | 홈 가격 데이터의 최근 갱신 시각 | 필수 |
| 상세 이동 | 품목별 상세 화면 연결 | 필수 |

### 2.2 수산물 카드

각 수산물은 개별 카드로 표시한다.

카드의 기본 정보는 다음과 같다.

| 항목 | 설명 |
|---|---|
| 수산물명 | 갈치, 고등어, 전복 |
| 평균가격 | 최근 확정 기간에 계산된 대표 평균가격 |
| 가격 단위 | 가격 집계에 적용된 표준 단위 |
| 가격 변동률 | 비교 기간 대비 가격 변동률 |
| 변동 방향 | 상승, 하락, 변동 없음 |
| 기준 기간 | 평균가격이 산출된 기간 |
| 상세 이동 | 해당 수산물 상세 화면으로 이동 |

가격이 존재하지 않을 경우 가격 영역에 `자료 없음`을 표시한다.

**주의:** 카드에 표시하는 가격은 KAMIS 중도매인 판매가격을 기반으로 집계한 값이다. 이를 소비자 실제 구매가격이나 전국 모든 시장의 확정 거래가격으로 표현하지 않는다.

## 3. 사용자 흐름

### 3.1 정상 흐름

1. 사용자가 오늘의 수산 모바일 웹에 접속한다.
2. 홈 화면이 열린다.
3. 시스템은 최초 제공 품목 3종의 가격 요약 데이터를 조회한다.
4. 각 품목의 평균가격과 변동률을 표시한다.
5. 사용자가 수산물 카드를 선택한다.
6. 선택한 품목의 상세 화면으로 이동한다.
7. 상세 화면에서 최근 완료 반월 24개 또는 완료 월 12개 가격 차트를 확인한다.

### 3.2 인증 정책

- 모든 사용자는 로그인 없이 홈 화면을 조회할 수 있다.
- 가격 정보 조회에 회원 식별 정보를 요구하지 않는다.
- 개인화된 품목 목록이나 즐겨찾기는 MVP에서 제공하지 않는다.

## 4. 기능 요구사항

### FR-HOME-01. 수산물 목록 제공

**요구사항**

홈 화면에서 갈치·고등어·전복 3종을 제공한다.

**상세 조건**

- 세 품목은 최초 출시 대상이다.
- 각 품목은 구분 가능한 카드 형태로 제공한다.
- 각 카드의 수산물명과 연결되는 품목 식별자는 일관되게 관리한다.
- 가격 데이터의 존재 여부에 따라 품목을 목록에서 임의로 제거하지 않는다.

**인수 조건**

- [ ] 홈 화면에 갈치·고등어·전복이 표시된다.
- [ ] 세 품목의 데이터가 서로 혼합되지 않는다.
- [ ] 특정 품목의 가격이 없더라도 해당 품목 카드는 유지된다.

### FR-HOME-02. 최근 확정 평균가격 표시

**요구사항**

각 품목의 최근 확정 평균가격을 표시한다.

**상세 조건**

- 대표 가격 출처는 KAMIS이다.
- 국산 생물로 분류된 적격 관측값만 대표 가격에 사용한다.
- 날짜별 시장 단순평균 후 기간별 평균을 적용한다.
- 산출된 가격의 기준 기간과 단위를 함께 제공한다.
- 소매가격으로 오인될 수 있는 문구는 사용하지 않는다.
- 홈 기준 기간은 가장 최근 완료 반월이다.
- 해당 완료 반월에 가격이 없으면 이전 유효 반월로 대체하지 않는다.
- 가격은 원 단위 정수로 반올림한다.

**인수 조건**

- [ ] 적격 가격 데이터가 있으면 계산된 평균가격을 표시한다.
- [ ] 가격 단위를 확인할 수 있다.
- [ ] 평균가격의 기준 기간을 확인할 수 있다.
- [ ] 냉동·수입으로 분류된 관측값이 대표 가격에 포함되지 않는다.
- [ ] 결측 구간에 0원이나 이전 가격을 대신 표시하지 않는다.

### FR-HOME-03. 가격 변동률 표시

**요구사항**

품목별 가격 변화 방향과 변동률을 제공한다.

**변동률 산식**

변동률(%) = (현재 기준가격 - 비교 기준가격) / 비교 기준가격 × 100

**상세 조건**

- 동일한 상품 분류 및 가격 집계 기준으로 계산된 기간끼리 비교한다.
- 변동률과 가격 변화 방향을 함께 제공한다.
- 가격이 상승하면 상승 상태를 표시한다.
- 가격이 하락하면 하락 상태를 표시한다.
- 두 가격이 같으면 변동 없음으로 표시한다.
- 비교 가격이 없거나 0원이면 변동률을 계산하지 않는다.
- 비교 기간은 바로 직전 반월이다.
- 변동률은 소수 첫째 자리로 반올림한다.

**인수 조건**

- [ ] 현재가격과 비교가격이 모두 유효할 때 변동률을 계산한다.
- [ ] 변동률의 부호와 상승·하락 방향이 일치한다.
- [ ] 비교가격이 없으면 임의 변동률을 표시하지 않는다.
- [ ] 비교가격이 0원이면 0으로 나누는 계산을 하지 않는다.
- [ ] 상승·하락을 색상에만 의존하지 않고 문자로도 구분한다.

### FR-HOME-04. 수산물 상세 화면 이동

**요구사항**

사용자가 수산물 카드를 선택하면 해당 품목의 상세 화면으로 이동한다.

**상세 조건**

- 카드마다 고유한 품목 식별자를 사용한다.
- 선택한 품목의 가격 차트와 분석 자료를 조회한다.
- 최초 상세 진입 시 차트 집계 단위는 15일이다.
- 상세 화면 최초 진입 시 선택된 가격 분석 기간은 없다.
- 별도의 로그인이나 권한 확인을 요구하지 않는다.

**인수 조건**

- [ ] 갈치 카드를 선택하면 갈치 상세 화면으로 이동한다.
- [ ] 고등어 카드를 선택하면 고등어 상세 화면으로 이동한다.
- [ ] 전복 카드를 선택하면 전복 상세 화면으로 이동한다.
- [ ] 상세 화면에서 다른 품목의 가격을 잘못 표시하지 않는다.
- [ ] 최초 상세 화면 진입 시 Price Insight는 기간 선택 안내 상태다.

### FR-HOME-05. 데이터 없음 및 오류 처리

**요구사항**

데이터가 없는 경우와 데이터 조회에 실패한 경우를 구분한다.

**상태 구분**

| 상태 | 조건 | 화면 처리 |
|---|---|---|
| 정상 | 유효한 가격 데이터 존재 | 평균가격 및 계산 가능한 변동률 표시 |
| 가격 자료 없음 | 정상 조회했으나 적격 가격 관측값 없음 | `자료 없음` 표시 |
| 변동률 계산 불가 | 현재가격 또는 비교가격 부족 | 가격은 유지하고 변동률을 계산 불가로 표시 |
| 조회 실패 | 서버 또는 네트워크 오류 | 가격을 임의 생성하지 않고 오류 안내 |
| 로딩 | 가격 데이터 조회 중 | 로딩 상태 표시 |

**인수 조건**

- [ ] 적격 가격이 없으면 `자료 없음`을 표시한다.
- [ ] 가격은 있지만 비교가격이 없으면 현재가격만 유지한다.
- [ ] 수집 실패를 실제 가격 0원으로 처리하지 않는다.
- [ ] 네트워크 오류 시 허위 가격이나 변동률을 표시하지 않는다.
- [ ] 오류 상황에서도 사용자에게 품목명이 유지된다.
- [ ] 한 품목 조회 실패 시 해당 카드와 다른 정상 카드를 유지하고 실패 카드에 재시도를 제공한다.

### FR-HOME-06. 초기 지원 품목 검색

**요구사항**

사용자가 갈치·고등어·전복을 이름으로 검색해 상세 화면으로 이동할 수 있게 한다.

**상세 조건**

- 검색 대상은 MVP 초기 지원 품목 3종이다.
- 검색어를 입력하면 지원 품목 3종을 즉시 필터링한다.
- 갈치·고등어·전복을 가리키는 일반명·표준명을 임의로 제외하지 않는다. 구체적인 동의어 매핑이 필요하면 별도 정책으로 검토한다.
- 미지원 품목은 결과 없음 상태로 안내한다.
- 검색 결과 선택 시 해당 품목 상세 화면으로 이동한다.
- 검색에 회원가입이나 로그인을 요구하지 않는다.

**인수 조건**

- [ ] `갈치`를 검색하면 갈치 결과가 표시된다.
- [ ] 검색 결과를 선택하면 해당 품목 상세 화면으로 이동한다.
- [ ] 미지원 품목을 검색하면 결과 없음 상태가 표시된다.
- [ ] 로그인하지 않은 이용자도 검색할 수 있다.
- [ ] 검색어 입력 즉시 3종 목록이 필터링된다.

## 5. 데이터 요구사항

### 5.1 데이터 출처

홈 화면의 대표 가격은 KAMIS 데이터를 기반으로 한다.

공공데이터포털의 공영도매시장 정산정보는 홈 화면의 대표가격을 산출하는 데 사용하지 않는다.

### 5.2 가격 계산

가격 계산은 PP-001의 공통 정책을 따른다.

1. KAMIS 원본 가격을 수집한다.
2. MVP 국산 생물 분류 규칙을 적용한다.
3. 적격 관측값을 식별한다.
4. 동일 날짜의 시장별 가격을 단순평균한다.
5. 기간 내 유효한 일별 평균을 단순평균한다.
6. 홈에 표시할 기준 기간의 평균가격을 조회한다.

### 5.3 데이터 품질

- 원본 값과 분류 결과를 보존한다.
- 관측일 수와 시장 수를 확인할 수 있어야 한다.
- 관측이 없는 기간은 0원으로 변환하지 않는다.
- 수집 실패와 관측자료 없음은 구분한다.
- 품질 기준을 충족하지 못한 가격의 표시 정책은 PP-001에서 결정한다.

## 6. 화면 상태별 동작

| 상황 | 기대 동작 |
|---|---|
| 최초 접속 | 3종 수산물 목록 조회 |
| 가격 조회 성공 | 기준가격과 가능한 변동률 표시 |
| 특정 품목 가격 없음 | 해당 품목 유지, 가격 자료 없음 표시 |
| 비교 기준가격 없음 | 현재가격 유지, 변동률 계산 불가 |
| 특정 품목 조회 실패 | 해당 카드 유지, 품목별 오류 및 재시도 제공 |
| 전체 조회 실패 | 모든 카드 유지, 오류 안내 및 재시도 제공 |
| 카드 선택 | 해당 품목 상세 화면 이동 |
| 로그인하지 않은 사용자 | 동일한 공개 가격 정보 조회 가능 |
| 정상 표시 | 각 카드의 가격 기준 기간과 홈 최근 갱신 시각 표시 |

## 7. 비기능 요구사항

### 7.1 모바일 사용성

- 모바일 화면을 기준으로 구성한다.
- 카드의 수산물명, 가격, 변동률을 읽기 쉽게 제공한다.
- 터치로 수산물 상세 화면에 이동할 수 있어야 한다.
- 가로 스크롤 없이 핵심 정보를 확인할 수 있도록 설계한다.

### 7.2 성능

- 사용자 요청마다 원천 KAMIS API를 직접 호출하는 구조를 기본값으로 사용하지 않는다.
- 사전에 수집·계산해 저장한 가격 요약 정보를 제공한다.
- 구체적인 API 응답시간과 화면 로딩시간 기준은 PP-003에서 확정한다.

### 7.3 접근성

- 상승·하락 상태는 색상 이외의 텍스트로도 표현한다.
- 가격 단위와 기준 기간을 명확히 제공한다.
- 카드 터치 영역은 모바일 사용에 적합하게 구성한다.

## 9. MVP 제외 기능

다음 기능은 홈 화면 MVP 범위에 포함하지 않는다.

- 회원가입 및 로그인
- 개인화된 수산물 추천
- 초기 지원 3종 외 수산물 검색
- 사용자별 즐겨찾기
- 가격 알림
- 제철 수산물 추천
- 상품 구매 및 결제
- 광고 및 유료 서비스

후속 버전에서 확장할 수 있으나 MVP의 필수 요구사항으로 취급하지 않는다.

## 10. 미정 사항

| ID | 항목 | 결정이 필요한 내용 |
|---|---|---|
| HOME-OPEN-01 | 최근 확정가격 | 확정 — 가장 최근 완료 반월, 이전 유효 반월 대체 금지 |

## 11. 출시 인수 기준

홈 화면은 다음 조건을 충족해야 출시할 수 있다.

- [ ] 갈치·고등어·전복 3종이 모두 표시된다.
- [ ] 유효한 최근 확정 평균가격을 조회할 수 있다.
- [ ] 대표 가격은 가장 최근 완료 반월만 사용하며 결측 시 이전 기간으로 대체하지 않는다.
- [ ] 변동률이 승인된 비교 정책과 산식에 따라 계산된다.
- [ ] 검색 입력 시 지원 품목 3종을 즉시 필터링한다.
- [ ] 기본 품목 순서는 갈치→고등어→전복이다.
- [ ] 카드별 가격 기준 기간과 홈 최근 갱신 시각을 표시한다.
- [ ] 품목별 조회 오류 시 카드를 유지하고 재시도를 제공한다.
- [ ] 가격 단위와 기준 기간을 확인할 수 있다.
- [ ] 가격 결측과 조회 실패를 허위 수치로 표현하지 않는다.
- [ ] 각 품목의 상세 화면으로 정상 이동한다.
- [ ] 로그인 없이 모든 핵심 기능을 이용할 수 있다.
- [ ] 모바일 화면에서 주요 정보를 확인하고 터치할 수 있다.
- [ ] QA 테스트 시나리오를 통과한다.
- [ ] 관련 출시 필수 정책과 QA 결과가 `PP-003` 기준으로 실제 검증되었다.

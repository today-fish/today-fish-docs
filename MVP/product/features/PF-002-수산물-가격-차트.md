# PF-002 수산물 가격 차트

> **핵심 결론:** 오늘의 수산 MVP는 KMI 산지가격과 KMI 도매가격 또는 aT 공영도매시장 정산가격을 가격 유형별로 독립 산출해 한 차트에 동등한 두 선으로 표시한다. 도매 기준 원천은 어종별 비교 가능성과 관측 품질을 검증해 선정한다. 일별 그룹은 유효 독립 관측 5건 이상이면 최고·최저 각 1건을 제외한 절사평균, 1~4건이면 중앙값으로 계산하고, 반월·월 가격은 유효 일별 가격을 단순 산술평균한다. 최근 완료 반월 24개 또는 완료 월 12개를 제공하며 진행 중 값과 결측 대체는 표시하지 않는다.
>
> - 문서 상태: DRAFT
> - 상위 문서: [PRD-001 MVP 제품 요구사항](../PRD-001-MVP-제품-요구사항.md)
> - 상위 기능: `CAP-CHART`
> - 관련 기능: [PF-001 홈 화면](./PF-001-홈-화면.md), [PF-003 Price Insight](./PF-003-Price-Insight.md), [PF-005 실시간 채팅](./PF-005-실시간-채팅.md)

## 1. 기능 목적

수산물 가격 차트는 이용자가 수산물 가격의 시간에 따른 변화를 살펴보고, 특정 기간에 발생한 가격 변화의 배경을 탐색할 수 있도록 돕는다.

### 1.1 사용자 목표

1. 수산물의 최근 24개 완료 반월 또는 12개 완료 월 가격 흐름을 확인한다.
2. 15일 또는 월별 단위로 가격 추이를 비교한다.
3. 관심 있는 기간과 가격 유형을 선택해 해당 가격을 확인한다.
4. 선택한 기간의 Price Insight를 조회한다.
5. 가격 데이터의 결측 여부와 관측 품질을 확인한다.

### 1.2 설계 원칙

- 가격 차트는 서비스의 핵심 정보 탐색 수단이다.
- 산지·도매 가격 유형을 독립된 시계열로 표시하며 서로 합치거나 대체하지 않는다.
- 실제 관측값을 기반으로 가격을 계산한다.
- 결측 가격을 추정하거나 보간하지 않는다.
- 차트의 시각적 표현이 원본 데이터의 의미를 왜곡하지 않아야 한다.
- AI 분석 결과가 없더라도 가격 차트는 독립적으로 제공한다.
- 상세 구현 규칙은 공통 데이터 정책을 따른다.

## 3. 화면 구성

### 3.1 상세 화면 내 배치

수산물 상세 화면은 다음 순서로 구성한다.

1. 수산물명
2. 가격 차트 영역
3. 차트 집계 단위 전환 버튼
4. 완료 기간 가격 차트
5. 선택 기간 정보
6. 선택 기간 산지·도매 가격
7. Price Insight
8. 최근 이슈

단, 집계 단위 전환 버튼은 차트 상단에 배치한다.

### 3.2 가격 차트 영역

| 구성 요소 | 표시 내용 |
|---|---|
| 차트 제목 | 수산물 가격 추이 |
| 가격 정의 | KMI 산지가격·KMI 또는 aT 도매가격을 독립 산출 |
| 집계 단위 | 15일 또는 월별 |
| 기본 집계 단위 | 15일 |
| 조회 범위 | 최근 24개 완료 반월 또는 최근 12개 완료 월 |
| X축 | 반월 또는 월별 기간 |
| Y축 | 표준 단위당 가격 |
| 데이터 점 | 산지·도매 유형별 집계 가격 |
| 선택 상태 | 선택 기간 및 선택한 가격 유형 |
| 결측 상태 | 유형별 자료 없음; 다른 선의 값은 유지 |
| 품질 정보 | 유형별 기준 원천, 유효 관측 건수·관측일 수 |

### 3.3 집계 단위 전환

차트 상단에 다음 전환 버튼을 제공한다.

`15일 | 월별`

- 최초 진입 시 `15일`이 활성화된다.
- `월별`을 선택하면 월별 평균가격 차트로 전환한다.
- 다시 `15일`을 선택하면 반월 차트로 전환한다.
- 집계 단위가 변경되면 기존 기간 선택은 초기화된다.
- 전환 후 Price Insight는 기간 선택 안내 상태로 돌아간다.

## 4. 가격 데이터 정의

### 4.1 대표 가격

산지 가격은 KMI 산지가격(`KMI_PRODUCER_PRICE`), 도매 가격은 KMI 도매가격(`KMI_WHOLESALE_PRICE`) 또는 aT 공영도매시장 정산가격(`AT_SETTLEMENT`)에서 각각 산출한다. 어종별 비교 가능성과 관측 품질을 검증해 도매 기준 원천을 선정한다. KAMIS는 MVP 수집 대상에서 제외한다. 유형·원천·상품 조건이 확인되지 않거나 서로 비교할 수 없는 관측값은 자동으로 같은 표본 집합에 넣지 않으며, 원천 간 임의 평균·결측 대체를 하지 않는다.

가격 계산에 사용하는 관측값은 다음 조건을 만족해야 한다.

1. MVP 제공 대상 수산물에 해당한다.
2. 가격 유형·기준 원천·상품 조건을 확인할 수 있다.
3. 유효한 가격과 비교 가능한 표준 단위를 가진다.
4. `VALID` 상태이며 독립 관측임을 확인할 수 있다.
5. 공통 데이터 검증 및 가격 집계 적격 기준을 충족한다.

### 4.2 가격 유형·상품 조건

각 관측값은 산지 또는 도매 가격 유형, 기준 원천, 상품 조건, 기준일, 단위를 확인할 수 있어야 한다. `GROUP` 품목 매핑만으로 상품의 가격 비교 가능성을 확정하지 않는다. 유형이나 상품 조건이 불명확한 관측은 자동 집계에서 제외하고 검토 대상으로 둔다. 검증 상태 `VALID`도 집계 적합성을 단독으로 보장하지 않는다.

상세 수집·정규화·검증 계약은 [BE-TECH-SPEC-001](../../architecture/backend/tech-spec/BE-TECH-SPEC-001-데이터-수집-정규화-검증.md), 가격 비교 및 계산 기준은 [BE-TECH-SPEC-002](../../architecture/backend/tech-spec/BE-TECH-SPEC-002-가격-데이터-모델링-및-산지-도매가격-산출.md)를 따른다.

### 4.3 가격 단위

- 서로 다른 단위의 가격을 직접 평균하지 않는다.
- 집계 전 공통 가격 단위로 정규화한다.
- 가격 차트의 Y축과 선택 기간 평균가격에 단위를 표시한다.
- 표준 단위와 환산 가능 여부는 원본 자료에 따라 결정한다.
- 환산이 불가능한 관측값을 임의로 변환하지 않는다.

## 5. 가격 집계 규칙

### 5.1 집계 원칙

가격은 다음 두 단계를 거쳐 산출한다. 서로 다른 가격 유형·기준 원천은 각각 독립 계산한다.

**1단계 — 일별 가격 산출:** 동일 날짜·어종·가격 유형·기준 원천·비교 가능한 상품 조건·표준 단위의 유효 독립 원본 관측을 한 그룹으로 묶는다. 각 그룹에 표본 수 규칙을 적용한다.

| 일별 그룹의 유효 독립 관측 건수 | 일별 대표가격 |
|---:|---|
| 5건 이상 | 최고값·최저값 각 1건을 제외한 나머지의 산술평균 |
| 1~4건 | 중앙값(짝수 건은 가운데 두 값의 산술평균) |
| 0건 | 해당 날짜의 일별 가격 미산출 |

**2단계 — 반월·월 가격 산출:** 유효 일별 가격을 단순 산술평균한다. 반월은 1~15일과 16일~월말, 월별은 1일~월말이다. 관측이 없는 날짜는 평균에서 제외하며 원본 관측 건수로 일별 가격에 가중치를 주지 않는다. 유효 일별 가격이 전혀 없으면 기간 가격을 산출하지 않는다. 다른 원천·유형의 값으로 대체하거나 결측을 보간하지 않는다.

`observation_count`는 절사 전 기간 내 적격 독립 원본 관측 총수, `excluded_count`는 일별 그룹에서 절사된 원본 관측 총수, `observed_day_count`는 기간 평균에 포함된 유효 일별 가격 수다. 기간 평균의 분모는 `observed_day_count`이며 원본 관측 수는 가중치가 아니다. 정상 극단값은 원본에서 보존하고, 계산 정책 버전 `price-aggregation-v2`를 적용한다. 자세한 계약은 [BE-TECH-SPEC-002](../../architecture/backend/tech-spec/BE-TECH-SPEC-002-가격-데이터-모델링-및-산지-도매가격-산출.md)를 따른다.

### 5.2 계산 예시

아래 예시는 일별 표본 수 처리와 기간 단순평균을 함께 보여준다. 모든 입력은 같은 날짜 그룹 조건을 만족하는 독립 관측이다.

| 날짜 | 원본 관측 가격 | 일별 결과 |
|---|---|---:|
| 1일 | 10,000, 14,000 | 12,000 (2건 중앙값) |
| 2일 | 1,000, 10,000, 20,000, 30,000, 100,000 | 20,000 (최고·최저 제외 후 평균) |
| 3일 | 관측 없음 | 미산출 |

기간 가격: `(12,000 + 20,000) / 2 = 16,000원`. 결과 지표는 `observation_count=7`, `excluded_count=2`, `observed_day_count=2`다. 3일은 분모에서 빠지며 원본 관측 건수로 잘못 가중하면 약 17,714원이 되어 단순평균과 달라진다.

### 5.3 집계 시 주의사항

- 유효 독립 관측이 없으면 가격을 만들지 않는다.
- 가격이 없는 날짜의 값은 0으로 처리하지 않는다.
- 산지·도매 유형이나 기준 원천을 서로 합치거나 대체하지 않는다.
- 관측 건수와 관측일 수는 가격 유형별로 관리한다.
- 집계 과정에서 원본 데이터의 출처와 처리 이력을 추적할 수 있어야 한다.

## 6. 기간 집계 정책

### 6.1 15일 집계

한 달을 다음 두 기간으로 구분한다.

| 구간 | 시작일 | 종료일 |
|---|---|---|
| 상반기 | 매월 1일 | 매월 15일 |
| 하반기 | 매월 16일 | 매월 말일 |

예시:

- 2026년 8월 상반기: 2026-08-01 ~ 2026-08-15
- 2026년 8월 하반기: 2026-08-16 ~ 2026-08-31
- 2026년 9월 하반기: 2026-09-16 ~ 2026-09-30

각 구간은 해당 기간에 관측된 유효 일별 가격으로 계산하며 산지·도매를 분리한다.

### 6.2 월별 집계

월별 가격은 매월 1일부터 말일까지 해당 가격 유형의 유효 일별 가격으로 산출한다.

예시:

2026년 8월 월별 가격은 2026-08-01부터 2026-08-31까지 관측된 유효 일별 평균가격으로 계산한다.

월별 가격은 두 반월 평균가격의 단순평균으로 계산하지 않는다.

### 6.3 월별 계산 시 주의사항

월별 집계는 해당 월의 유효 일별 가격만을 기준으로 하며 미관측 일자를 임의로 채우지 않는다.

### 6.4 윤년 및 월말 처리

- 2월 말일은 연도에 따라 28일 또는 29일로 처리한다.
- 30일까지 존재하는 월은 30일을 하반기 종료일로 사용한다.
- 31일까지 존재하는 월은 31일을 하반기 종료일로 사용한다.
- 날짜 범위는 시작일과 종료일을 모두 포함한다.

### 6.5 완료 기간 조회

- 기본 반월 차트는 가장 최근 완료 반월을 끝점으로 최근 24개 완료 반월을 표시한다.
- 월별 차트는 가장 최근 완료 월을 끝점으로 최근 12개 완료 월을 표시한다.
- 반월과 월은 완료되는 시점이 다르므로 두 차트의 종료 시점은 달라도 된다.
- 진행 중인 반월·월의 잠정값은 포함하지 않는다.

## 7. 사용자 상호작용

### FR-CHART-01. 완료 기간 가격 차트 표시

**요구사항**

수산물 상세 화면 진입 시 최근 24개 완료 반월 가격 차트를 표시한다.

**상세 조건**

- 기본 집계 단위는 15일이다.
- 최초 진입 시 선택된 기간은 없다.
- 가격 차트는 적격 관측값에 기반한다.
- 가격이 없는 기간은 결측으로 표현한다.
- 차트는 로그인 없이 조회할 수 있다.
- 차트 시계열은 가로 스크롤 없이 차트 너비 안에 전체 표시한다(`UX-D05`).

**인수 조건**

- [ ] 상세 화면 최초 진입 시 15일 차트가 표시된다.
- [ ] 최초 진입 시 선택된 가격 기간이 없다.
- [ ] 가격이 존재하는 구간에만 유효한 가격 점이 표시된다.
- [ ] 결측 가격을 0원으로 표현하지 않는다.
- [ ] 최초 Price Insight 영역에는 기간 선택 안내가 표시된다.
- [ ] 최근 24개 완료 반월이 차트 너비 안에 전체 표시되고 진행 중 반월은 제외된다.

### FR-CHART-02. 집계 단위 전환

**요구사항**

사용자는 15일과 월별 차트를 전환할 수 있다.

**상세 조건**

- 차트 상단에 전환 버튼을 제공한다.
- 기본 선택은 15일이다.
- 사용자가 월별을 선택하면 월별 집계 결과를 표시한다.
- 사용자가 다시 15일을 선택하면 반월 집계 결과를 표시한다.
- 단위를 실제로 변경하면 선택된 기간을 해제한다.
- 단위 전환으로 인해 잘못된 분석 기간이 유지되지 않아야 한다.
- 월별은 최근 12개 완료 월을 표시하며 진행 중 월은 제외한다.

**인수 조건**

- [ ] 15일에서 월별로 전환할 수 있다.
- [ ] 월별에서 15일로 전환할 수 있다.
- [ ] 전환 후 올바른 기간별 집계 결과가 표시된다.
- [ ] 단위 변경 시 이전 기간 선택이 해제된다.
- [ ] 단위 변경 시 Price Insight는 기간 선택 안내 상태로 초기화된다.

### FR-CHART-03. 차트 기간 선택

**요구사항**

사용자가 가격 차트의 유효한 데이터 점을 터치하면 해당 기간을 선택한다.

**상세 조건**

- 15일 차트는 해당 반월 기간을 선택한다.
- 월별 차트는 해당 월 전체를 선택한다.
- 선택한 기간은 다른 기간과 시각적으로 구분한다.
- 선택한 기간의 시작일과 종료일을 확인할 수 있다.
- 선택 기간을 변경하면 평균가격과 Price Insight 조회 대상도 변경한다.
- 결측 구간을 정상 가격 데이터처럼 선택하지 않는다.
- 결측 기간을 터치하면 화면 크기에 맞는 `자료 없음` 안내만 표시한다(`UX-D15`).
- 기존 유효 기간을 선택한 상태에서 결측을 터치하면 기존 선택과 Insight를 유지한다(`UX-D28`).

**인수 조건**

- [ ] 2026년 8월 상반기 점을 선택하면 8월 1~15일이 선택된다.
- [ ] 2026년 8월 하반기 점을 선택하면 8월 16~31일이 선택된다.
- [ ] 월별 차트에서 2026년 8월을 선택하면 8월 전체가 선택된다.
- [ ] 선택한 기간을 화면에서 구분할 수 있다.
- [ ] 다른 점을 선택하면 이전 선택 대신 새 기간이 적용된다.
- [ ] 결측 구간이 유효한 가격 점으로 오인되지 않는다.

### FR-CHART-04. 선택 기간 평균가격 표시

**요구사항**

차트의 가격 점을 선택하면 해당 기간과 가격 유형을 표시한다.

**상세 조건**

- 선택한 점의 가격 유형과 기간을 명시한다. 같은 기간의 산지·도매 값은 각각 표시하고 선택한 유형을 강조한다.
- 가격 단위를 표시한다.
- 가격 표시값은 원 단위 정수로 반올림한다(`PFV-004`).
- 차트 화면에서 변동률을 표시하는 경우 소수 첫째 자리로 반올림한다(`PFV-005`).
- 가격 유형별 유효 독립 관측 건수 규칙을 적용하고 산지·도매를 섞지 않는다.
- 가격 집계 적격성과 표본 수는 승인된 BE-TECH-SPEC-001/002 기준을 따른다.
- CSS viewport 너비 767px 이하는 차트 하단 고정 정보 영역, 768px 이상은 차트 내부 툴팁으로 선택 정보를 표시한다(`UX-D06`, Q32).
- 768px은 제품 설계 기준이며 표준 강제값이 아니다. 좁은 컨테이너나 화면 가장자리에서 잘림이 발생하면 위치 조정·경계 처리로 대응하고 전환 너비는 별도 승인 없이 바꾸지 않는다.

**인수 조건**

- [ ] 가격 점 선택 시 기간·가격 유형·가격이 식별된다.
- [ ] 같은 기간의 산지·도매 값은 각각 표시되며, 다른 유형 점 선택 시 선택 유형 강조가 변경된다.
- [ ] 15일과 월별 집계 결과가 혼동되지 않는다.
- [ ] 유효한 관측값만 가격 계산에 포함된다.
- [ ] 가격 단위를 확인할 수 있다.
- [ ] 가격은 원 단위 정수로 표시되고, 표시되는 변동률은 소수 첫째 자리로 표시된다.
- [ ] 767px 이하에서는 선택 기간·유형별 가격을 차트 하단 고정 정보 영역에 표시한다.
- [ ] 768px 이상에서는 선택 가격 정보를 차트 내부 툴팁으로 표시한다.
- [ ] 경계 너비 767px과 768px에서 표시 방식이 각각 하단 정보 영역·차트 내부 툴팁으로 전환된다.
- [ ] 툴팁이 좁은 컨테이너나 화면 가장자리에서 잘리지 않으며, 필요 시 위치·경계를 조정한다.

### FR-CHART-05. 결측값 표현

**요구사항**

가격이 없는 기간은 데이터가 없는 상태로 표현한다.

**상세 조건**

- 결측 가격을 0원으로 표시하지 않는다.
- 이전 가격을 복사하지 않는다.
- 임의 보간을 수행하지 않는다.
- 냉동·수입산 가격으로 대체하지 않는다.
- 중간 결측 구간을 가로질러 차트 선을 연결하지 않는다.
- 차트의 결측 상태를 `자료 없음`으로 확인할 수 있어야 한다.

**인수 조건**

- [ ] 유효 가격이 없는 기간은 0원으로 표시되지 않는다.
- [ ] 결측 전후의 가격 점이 연속된 관측처럼 연결되지 않는다.
- [ ] 결측 기간에 임의 가격 점이 생성되지 않는다.
- [ ] 냉동·수입산 가격으로 대체하지 않는다.
- [ ] 사용자가 해당 기간에 가격 자료가 없음을 알 수 있다.

### FR-CHART-06. 관측 품질 정보

**요구사항**

기간별 가격의 데이터 품질을 확인할 수 있도록 한다.

**표시 대상 정보**

- 가격 관측일 수
- 가격 유형별 유효 관측 건수
- 집계 대상 기간
- 가격 데이터 출처

**상세 조건**

- 관측일 수는 실제 유효한 가격이 존재한 날짜를 기준으로 한다.
- 가격 유형별 유효 관측 건수와 관측일 수를 구분한다.
- 가격 유효성과 비교 가능성은 승인된 BE-TECH-SPEC-001/002 기준을 따른다.

**인수 조건**

- [ ] 기간별 관측일 수를 확인할 수 있다.
- [ ] 산지·도매 각각의 유효 관측 건수와 관측일 수를 확인할 수 있다.
- [ ] 가격이 없는 기간의 관측일 수를 허위로 생성하지 않는다.
- [ ] 중복 레코드로 유효 관측 건수가 과대 계산되지 않는다.
- [ ] 차트 하단에 유형별 관측 건수·관측일 수 요약이 표시된다.
- [ ] 인라인 Accordion에서 집계 대상 기간·유형·원천·관측 건수·관측일 수·집계 기준을 확인할 수 있다.
- [ ] 관측 품질 표시를 위해 가격 산식이나 적격 관측 기준을 변경하지 않는다.

### FR-CHART-07. Price Insight 연동

**요구사항**

선택한 가격 기간에 해당하는 Price Insight를 조회한다.

**상세 조건**

- 차트 최초 진입 시 Insight를 자동 선택하지 않는다.
- 가격 기간을 선택하면 해당 기간의 저장된 Insight를 조회한다.
- 분석 조회에는 품목, 집계 단위, 시작일, 종료일을 사용한다.
- 15일 차트에서는 선택한 반월의 분석 결과를 조회한다.
- 월별 차트에서는 선택한 월 전체의 분석 결과를 조회한다.
- AI 분석 결과가 없어도 가격 차트는 유지한다.
- AI 해석이 없는 경우 해석 영역에 `파악 중`을 표시한다.

**인수 조건**

- [ ] 상세 최초 진입 시 Insight는 기간 선택 안내 상태다.
- [ ] 15일 차트에서 기간을 선택하면 해당 반월 분석을 조회한다.
- [ ] 월별 차트에서 기간을 선택하면 해당 월 전체 분석을 조회한다.
- [ ] 선택 기간이 변경되면 분석 조회 대상도 변경된다.
- [ ] AI 분석 생성 실패 시에도 가격 차트는 정상 표시된다.
- [ ] AI 해석 미생성 상태가 가격 데이터 결측으로 처리되지 않는다.

### FR-CHART-08. 수집 실패 및 오류 처리

**요구사항**

가격 데이터가 실제로 없는 경우와 수집 또는 조회 과정에 문제가 발생한 경우를 구분한다.

**상세 조건**

- 원천 데이터 수집 실패와 정상 수집 후 관측자료 없음을 내부적으로 구분한다.
- 조회 실패를 `가격 0원`으로 변환하지 않는다.
- 데이터 조회 오류가 발생하면 오류 상태를 표시한다.
- AI 분석 실패가 가격 조회 실패로 전파되지 않도록 한다.
- 오래된 가격 데이터를 사용해야 하는 경우 최신성 안내 정책을 따른다.

**인수 조건**

- [ ] 정상 조회 결과 관측자료가 없으면 자료 없음 상태로 처리한다.
- [ ] API 오류는 실제 자료 없음과 별도 상태로 기록한다.
- [ ] 조회 오류 시 임의 가격을 반환하지 않는다.
- [ ] AI 분석 오류가 정상 가격 차트를 제거하지 않는다.
- [ ] 데이터 조회가 실패해도 다른 품목의 가격으로 대체하지 않는다.

## 8. 차트 상태 관리

### 8.1 주요 상태

| 상태 | 설명 |
|---|---|
| INITIAL | 상세 최초 진입, 기간 미선택 |
| LOADING | 가격 데이터 조회 중 |
| READY | 가격 데이터 조회 완료 |
| PERIOD_SELECTED | 유효한 가격 기간 선택 |
| PARTIAL_DATA | 일부 기간 가격 결측 |
| NO_DATA | 조회 범위 전체에 유효 가격 없음 |
| ERROR | 데이터 조회 실패 |

위 상태는 개념적 구분이며 실제 구현에서는 집계 단위, 선택 기간, 데이터 조회 상태를 각각 관리할 수 있다.

### 8.2 상태 전이

```mermaid
flowchart TD
    A[상세 화면 최초 진입] --> B[15일 차트 조회]
    B --> C{조회 결과}
    C -->|가격 존재| D[차트 표시·기간 미선택]
    C -->|일부 결측| E[결측 구간 포함 차트]
    C -->|전체 자료 없음| F[자료 없음 상태]
    C -->|조회 실패| G[오류 상태]
    D --> H[가격 점 선택]
    E --> H
    H --> I[기간 평균가격 표시]
    I --> J[해당 기간 Price Insight 조회]
    D --> K[집계 단위 변경]
    E --> K
    I --> K
    J --> K
    K --> L[선택 해제]
    L --> M[변경된 단위로 차트 표시]
    M --> H
```

### 8.3 선택 상태 초기화

다음 경우에는 선택된 분석 기간을 초기화한다.

- 품목 상세 화면에 최초 진입한 경우
- 15일에서 월별로 집계 단위를 변경한 경우
- 월별에서 15일로 집계 단위를 변경한 경우

품목 변경 또는 상세 화면 재진입 시 선택 상태를 복원할 것인지는 MVP의 별도 정책으로 정의하지 않았으므로, 현재는 최초 진입 시 미선택이라는 확정 요구사항을 우선 적용한다.

## 9. 데이터 조회 계약

본 절은 프론트엔드와 백엔드 간 필요한 데이터의 논리적 구조를 정의한다.

구체적인 REST 경로, DB 테이블, 기술 스택은 확정하지 않는다.

### 9.1 조회 요청

필요한 입력 정보는 다음과 같다.

| 필드 | 의미 | 필수 |
|---|---|---|
| species_id | 수산물 식별자 | 필수 |
| granularity | 집계 단위: HALF_MONTH / MONTH | 필수 |
| 조회 시작일 | 조회 범위 시작일 | 필수 |
| 조회 종료일 | 조회 범위 종료일 | 필수 |

### 9.2 가격 구간 응답

각 구간에는 다음 정보가 필요하다.

| 필드 | 의미 |
|---|---|
| species_id | 수산물 식별자 |
| granularity | 집계 단위 |
| period_start | 집계 시작일 |
| period_end | 집계 종료일 |
| producer_price | 기간 산지가격. 결측 가능 |
| wholesale_price | 기간 도매가격. 결측 가능 |
| selected_price_type | 선택 가격 유형: PRODUCER / WHOLESALE |
| unit | 가격 표준 단위 |
| observed_days | 유효 가격 관측일 수 |
| producer_observation_count | 산지 유효 관측 건수 |
| wholesale_observation_count | 도매 유효 관측 건수 |
| data_status | 가격 데이터 상태 |
| source | 가격 데이터 출처 |

### 9.3 데이터 상태 값 제안

| 상태 코드 | 의미 |
|---|---|
| AVAILABLE | 정상 가격 존재 |
| NO_OBSERVATION | 정상 수집 결과 적격 관측값 없음 |
| COLLECTION_FAILED | 원천 수집 실패 |
| QUALITY_REVIEW_REQUIRED | 관측 품질 확인 필요 |

상태 코드는 개념적 구분이며 가격 적격성은 승인된 Tech Spec 기준을 따른다.

특히 수집 실패가 발생한 기간에 기존 저장 데이터가 일부 존재할 수 있으므로, 실제 구현에서는 가격 존재 여부와 수집 실행 상태를 하나의 값으로 단순 통합하지 않도록 검토한다.

### 9.4 Price Insight 조회 조건

분석 결과를 식별하기 위해 다음 값이 필요하다.

- species_id
- granularity
- period_start
- period_end

조회 조건은 현재 선택한 차트 기간과 정확히 대응해야 한다.

월별 분석 결과를 두 반월 분석 결과의 단순 결합으로 대신하지 않는다.

## 10. 경계 조건과 예외 처리

### 10.1 관측일이 하루뿐인 경우

유효 독립 일별 관측값 1~4건은 중앙값으로 산출한다.

일별 가격은 유효 독립 관측 건수에 따라 집계하고, 기간 가격은 존재하는 유효 일별 가격만 사용한다.

### 10.2 가격 유형별 관측값이 존재하는 경우

가격 유형별 유효 독립 관측값을 사용하며 5건 이상은 최고·최저 각 1건을 제외하고, 1~4건은 중앙값을 사용한다.

가격 유형별 데이터 가용성을 확인할 수 있도록 유효 관측 건수와 관측일 수를 보존한다.

시장 수를 최소 표본 기준으로 사용하지 않는다. 승인된 독립 관측 건수 기준을 적용한다.

### 10.3 가격 유형별 유효 관측이 없는 경우

해당 날짜는 해당 가격 유형의 일별 가격을 계산하지 않는다.

구간에 유효한 일별 가격이 없으면 해당 유형의 기간 가격은 결측으로 처리한다.

### 10.4 특정 기간의 데이터 수집이 실패한 경우

수집 실패를 가격 0원 또는 관측자료 없음과 동일하게 처리하지 않는다.

수집 실행 기록에서 오류 상태를 확인할 수 있어야 한다.

### 10.5 가격 이상치가 존재하는 경우

가격이 극단적으로 높거나 낮더라도 가격 편차가 크다는 이유만으로 정상 관측을 제거하지 않는다.

명백한 단위 오류·파싱 오류처럼 검증된 오류만 제외한다.

### 10.6 동일 관측 중복 데이터가 존재하는 경우

동일 관측의 완전 중복만 집계 입력에서 제외한다. 원본은 보존한다.

서로 다른 등급 또는 규격은 독립 관측으로 구분·보존한다. 이를 대표가격 하나에 혼합할지는 `PFV-013`으로 보류한다. 상품 조건 혼합이 의심되면 실제 데이터를 확인하며 검증 없이 일괄 포함하거나 제외하지 않는다.

### 10.7 분석 결과가 존재하지 않는 경우

가격 데이터는 정상 표시한다.

검증된 사실이 있다면 유지하고, AI 해석이 없는 영역만 `파악 중`으로 표시한다.

### 10.8 과거 가격 데이터가 정정된 경우

원천 가격의 변경이 확인되면 영향을 받는 기간의 평균가격을 재계산할 수 있어야 한다.

연결된 Price Insight의 재분석 및 버전 처리 기준은 PP-002에서 정의한다.

## 12. 비기능 요구사항

### 12.1 모바일 사용성

- 모바일 화면에서 차트 시계열 전체를 차트 너비 안에 표시해야 한다.
- 차트 점을 터치하여 기간을 선택할 수 있어야 한다.
- 선택한 기간을 시각적으로 구분해야 한다.
- 가격과 기간 정보가 화면 밖으로 잘리지 않아야 한다.
- 집계 단위 전환 버튼은 터치하기 쉬운 형태로 제공한다.
- 접근성을 위해 가격 정보를 색상에만 의존해 전달하지 않는다.

### 12.2 데이터 정확성

- 일별 그룹별 표본 수 규칙과 기간의 유효 일별 가격 단순평균이 각각 일치해야 한다.
- 날짜 경계를 올바르게 처리해야 한다.
- 결측값을 계산 과정에 포함하지 않아야 한다.
- 가격 단위가 서로 다른 데이터를 검증 없이 합산하지 않아야 한다.
- 원본 데이터와 집계 결과의 추적이 가능해야 한다.

### 12.3 운영 안정성

- 사용자 조회 시 원천 aT·KMI API 호출을 필수로 요구하지 않는다.
- 사전에 수집·계산된 결과를 조회할 수 있도록 설계한다.
- 원천 데이터 수집 실패를 기록한다.
- AI 분석 실패가 가격 조회를 중단시키지 않아야 한다.
- 가격 데이터 갱신 및 정정에 따른 집계 재처리가 가능해야 한다.

### 12.4 성능

다음 성능 목표는 `PP-003`을 따른다.

- 가격 차트 조회 API p95 ≤ 500ms
- 차트 최초 렌더링 시간
- 집계 단위 전환 응답시간
- 기간 선택 후 평균가격 표시시간
- Price Insight 조회 응답시간

## 14. 출시 인수 기준

수산물 가격 차트 기능은 다음 조건을 모두 충족해야 MVP 출시가 가능하다.

### 14.1 기능 검증

- [ ] 갈치·고등어·전복의 가격 차트를 조회할 수 있다.
- [ ] 최근 완료 반월 24개와 완료 월 12개 가격 흐름을 표시한다.
- [ ] 기본 집계 단위는 15일이다.
- [ ] 15일·월별 전환이 가능하다.
- [ ] 집계 단위 변경 시 기간 선택이 초기화된다.
- [ ] 차트 점을 터치해 기간을 선택할 수 있다.
- [ ] 선택 기간 평균가격을 확인할 수 있다.
- [ ] 가격은 원 단위 정수로, 표시되는 변동률은 소수 첫째 자리로 반올림한다.
- [ ] 월별 선택 시 해당 월 전체 Insight를 조회한다.

### 14.2 데이터 검증

- [ ] 동일 날짜 그룹의 유효 관측 0건·1건·4건·5건 경계를 검증한다.

- [ ] `observation_count`, `excluded_count`, `observed_day_count`의 집계 의미와 결과가 일치한다.
- [ ] 유효하지 않은 관측값을 대표 가격에서 제외한다.
- [ ] 결측값을 0으로 처리하지 않는다.
- [ ] 결측 구간을 임의 보간하지 않는다.
- [ ] 냉동·수입산 가격으로 생물 가격을 대체하지 않는다.
- [ ] 가격 유형별 유효 관측 건수와 관측일 수를 확인할 수 있다.
- [ ] 완전 중복과 검증된 오류만 제외하며 정상 극단값을 편차만으로 제거하지 않는다.
- [ ] 서로 다른 등급·규격을 독립 관측으로 보존하고 혼합 여부를 `PFV-013` 확정 전 임의 결정하지 않는다.

### 14.3 운영 검증

- [ ] 수집 실패와 실제 관측자료 없음을 구분한다.
- [ ] AI 분석이 없어도 가격 차트를 조회할 수 있다.
- [ ] 데이터 정정 시 영향받는 기간을 재계산할 수 있다.
- [ ] 모바일 화면에서 주요 기능을 정상 사용할 수 있다.
- [ ] 승인된 성능 및 데이터 품질 기준을 충족한다.

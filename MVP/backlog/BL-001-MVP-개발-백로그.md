## 개요

이 백로그는 MVP 개발 작업을 **L1 11개와 L2 54개**로 나눈 1차 목록이다. L1 중 5개는 사용자 기능 `Feature`, 6개는 독립 기술 목표 `Task`다. 각 L2 행은 **하나의 변경 목적과 검증 가능한 결과**를 가진 GitHub Issue 한 개·PR 한 개의 기본 단위다. PR의 커밋은 그 목적을 완성하는 작은 변경 단계로 구성한다. 아래 ID는 백로그 식별자이며 실제 GitHub Issue 번호가 아니다. 현재 생성된 Issue는 없다.

L2 표의 `BE`·`FE`는 변경 대상 저장소를 뜻하며 Project의 `Workstream`과 구분한다. 행은 상위 L1별로 묶었으며 ID 순서가 구현 순서를 뜻하지 않는다. 기능·기술 구현의 상세 계약은 관련 승인 문서를 따른다. L1-11은 출시 인수 기준의 KPI 계측 범위를 담으며, 익명 이용자 식별·동의·보관 방식과 목표 수치는 이 백로그에서 정의하지 않는다.

| L1 — Task    |   6 |
| L1 합계      |  11 |

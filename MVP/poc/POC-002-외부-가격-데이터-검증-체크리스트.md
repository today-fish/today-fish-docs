# POC-002 외부 가격 데이터 PoC 공통 체크리스트

새로운 데이터 소스를 발견하면 다음 항목을 확인한다.

| 검증 항목      | 확인 내용                    |
| ---------- | ------------------------ |
| API 접근     | 실제 호출이 가능한가              |
| 품목         | 원하는 수산물이 존재하는가           |
| 실제 데이터     | 품목코드가 아니라 실제 거래가 존재하는가   |
| 최신성        | 최근 데이터가 계속 갱신되는가         |
| 연속성        | 날짜별 데이터가 충분히 이어지는가       |
| 데이터량       | 대표가격을 계산할 만큼 충분한가        |
| 과거 데이터     | 전년 동기 비교가 가능한가           |
| 단위         | 원/kg 등으로 정규화 가능한가        |
| 품목 Mapping | 기관별 코드와 내부 품목을 연결할 수 있는가 |
| 시장 정보      | 시장별 가격 비교가 가능한가          |
| 자동수집       | Batch로 안정적으로 가져올 수 있는가   |
| 출처         | 사용자에게 원본 출처를 보여줄 수 있는가   |
